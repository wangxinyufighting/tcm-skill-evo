## 需要你自己下载/整理的

**① 教材方剂表 `kb/formulas.csv`**（可选，仅用于 `analyze_skills.py --formulas`）

格式（UTF-8，首行可为表头）：

```csv
方名,组成,主治
麻黄汤,麻黄、桂枝、杏仁、炙甘草,外感风寒表实证。恶寒发热，头身疼痛，无汗而喘……
```

来源建议：
- 《方剂学》规划教材的方剂目录（约 300–400 首，最贴合"重发现教材知识"的叙事）；
- 国家人口健康科学数据中心·中医药主题的方剂数据库（https://www.ncmi.cn，需注册）；
- TCM-MKG（Zenodo record 15395588，开源表格，约 1.1GB；请自行确认方剂表字段）。

我这里的环境访问不到 Zenodo / HuggingFace，所以没法替你下载核对；为避免组成写错，我也没有凭记忆生成方剂表。

**② 外部临床数据集**（可选，强烈建议做一个）

PTM 来自方剂库，经典方很可能出现在大模型的预训练语料里。一个预训练里不太可能出现的临床数据集能显著增强结论说服力，例如：
- CCL2025-Eval 任务 9（中医辨证辨病 + 中药处方推荐）的评测数据；
- 合作医院 / 名老中医的真实医案（如有）。

接入方式：整理成与 `data/processed/cases.jsonl` 相同字段（cid, split, desc, symptoms, herbs, cat, flags），放到新的 processed 目录，用 `--set paths.processed_dir=...` 运行即可（药名会经 `herb_aliases.json` 归一化，必要时补别名）。
